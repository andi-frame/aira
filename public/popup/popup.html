🤖 Model AI Semantik (LLM)
ℹ️ Status Fitur Saat Ini:
⚠️ Mode Fallback Lokal (Tanpa API Key LLM) Aktif:
• Berjalan Normal: Form Wizard 1-per-1, validasi format lokal (NIK 16 digit, No HP, Tanggal), navigasi tombol, pembaca suara TTS, dan adaptasi kontras tinggi.
• Fitur yang Berjalan Terbatas Tanpa LLM:
  • Pemahaman Bahasa Santai: Navigasi suara hanya mengenali kata kunci tombol yang ada, bukan maksud kalimat bebas/tidak baku.
  • Penjelasan Istilah Birokrasi: Menggunakan kamus template standar untuk NIK/BPJS/Nama/Alamat, bukan penjelasan dinamis dari teks halaman.
  • Perangkuman Halaman: Menggunakan ringkasan statistik struktur (jumlah formulir dan tombol), bukan intisari pemahaman konteks mendalam.
🎙️ Pengenalan Suara (Speech-to-Text)

Default menggunakan Google Web Speech API Chrome secara lokal; 9Router Whisper tersedia untuk rekaman remote/server dan dapat dipilih saat diperlukan.

🔊 Pembaca Suara (Text-to-Speech)

Prioritas utama menggunakan ElevenLabs suara alami Indonesia; fallback otomatis ke Google/Microsoft TTS jika API key kosong.
